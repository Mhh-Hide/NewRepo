# 权限原则

| 角色     | 已确认约束                                             |
| -------- | ------------------------------------------------------ |
| 产品运营 | 可查看完整业务数据                                     |
| 采购     | 不可查看客户身份及客户售价                             |
| 模型测试 | 不可查看客户身份及客户售价                             |
| 运维     | 可查看客户与供应商身份；不可查看客户售价、采购商业折扣 |
| 供应商   | 仅访问自身授权数据                                     |
| 前台人员 | 不可查看供应商真实身份                                 |

未明确的角色权限不推定为允许。多角色冲突、行级授权、字段级授权、导出权限待确认。
未来三档价格可见性与报价权限分离，规则见 BUSINESS_RULES 第 20 条，本期不实现。

当前无登录、角色切换或权限引擎。UI 可见性仅属体验；真实授权由后端强制执行，不可通过前端隐藏字段冒充生产级控制。Mock 也不能包含真实敏感信息。

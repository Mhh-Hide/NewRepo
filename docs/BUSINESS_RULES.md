# 已确认业务原则

1. 模型由厂商提供，同一模型可有多个供应商。
2. 一个供应商可以提供多个模型。
3. 同一供应商针对同一模型可以有不同渠道类型。
4. 渠道是报价、测试、接入管理的最小操作单元。
5. 每条渠道具有独立且不可重复的内部渠道 ID。
6. OP 渠道 ID 单独存储，允许初期为空。
7. 质量测试和连通性测试是两个独立阶段。
8. 所有渠道都需要连通性测试。
9. 经核验的官方原厂 Key 可按规则跳过质量测试；核验标准与豁免细则待确认。
10. 供应商报价区分参考报价、正式价格、临时优惠。
11. 已确认价格变更必须保留历史记录。
12. 报价、测试及关键状态变更需要操作审计。
13. 国内/海外业务域按模型厂商归属划分，不按模型销售地区划分。
14. 采购不能查看客户身份及客户售价。
15. 测试不能查看客户身份及客户售价。
16. 运维可以查看客户与供应商身份，但不能查看任何客户售价及采购商业折扣。
17. 供应商只能访问自身授权数据。
18. 产品运营能够查看完整业务数据。
19. 前台人员不能查看供应商真实身份。
20. 后续销售、总监、VP 三档价格同时展示给有权限的前台人员；用户等级影响报价权限，不影响三档价格可见性。本期不开发。

本阶段仅记录，不实现上述业务。价格币种、计价单位、有效期、精度、确认流程、审计保留周期待详细 PRD，不自行定义。

## 第 01 阶段实现补充

以上原则保留。原“本阶段仅记录”指第 00 阶段；第 01 阶段已实现实体、Mock 查询、纯规则与权限测试，仍未实现真实业务页面或写流程。

- 模型按厂商归属推导业务域；Seedance 国内/海外版本都属于国内模型域。
- 模型身份用厂商、modelCode、version、regionVariant 区分。
- 供应商不固定业务域；名称、缩写分别唯一，稳定 ID 不随名称变化。
- 渠道 id 独立；同供应商同模型可多渠道；OP 初始 null，绑定后纯函数拒绝随意覆盖。
- 能力未知为 null；折扣使用万分比整数品牌类型，演示范围 0..10000，显示“几折”不在领域层计算。
- 价格以只读历史列表提供；appendQuote 只追加新 id；更正记录标记 correction 并链接原记录。促销必须有独立有效期，不覆盖长期记录；本期不决定叠加或优先级。
- 质量豁免必须官方原厂类型 + 来源 verified + 独立证据记录；所有渠道都有连通性任务，连通性没有 exempted 状态。
- supplierCoverage 按不同供应商计数并报告距三家的缺口；不足三家不会阻止保存示例或查询。
- 事件不含自动罚款、欺诈认定逻辑；前端审计仅模拟，不保证持久性或防篡改。

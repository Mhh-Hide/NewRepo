- D01-03：单一活动角色 + 业务域、供应商、客户独立授权；多角色冲突 TBD。默认拒绝，前台不支持按隐藏供应商 ID 查询。

- D01-07：UI 目录通过 ESLint 禁止直接导入 mocks，统一走 services；欢迎页和第 00 阶段测试保持不变。没有新增依赖。
- D01-08：审计接口仅产品运营授权域可读，避免快照泄露采购折扣；后端持久化、防篡改和细粒度审计投影 TBD。

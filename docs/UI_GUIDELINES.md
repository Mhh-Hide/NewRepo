# UI 基础

使用 React + TypeScript 与 Ant Design，中文为默认展示语言。路由由 React Router 管理。
第 00 阶段交付为欢迎页；第 02 阶段扩展范围见下，后续未授权业务模块仍不得提前开发。

保持语义化标题、可读布局、移动端不溢出。业务 UI 放入对应 feature；共享组件只在有实际复用需求时提取，修改前检索所有引用。
后续加载、空态、错误反馈、表单校验、表格筛选规范随 PRD 确认。权限判断独立于 UI，隐藏字段不构成安全控制。

## Stage 02：应用外壳与工作台

采用浅灰背景、白色内容卡片、深蓝侧栏、克制的品牌蓝。默认简体中文，组件优先使用 Ant Design；图标显式依赖其官方 @ant-design/icons，不引入其他 UI 框架。标题约 27px，区块标题约 14px，正文 12–14px；数字用清晰的千位分隔，未知能力展示“未知”，不补零。

布局：桌面固定 232px 左侧栏，可收起为 76px；顶部展示系统名、Mock 标识、业务域和演示身份。中央 PageHeader 统一面包屑、标题、说明与只读刷新操作。1440px/1280px 优先，窄屏用抽屉导航；卡片随宽度重排，宽表格在卡片内横向滚动，不让整个页面溢出。

导航唯一真值为 src/app/navigation.tsx，含 ID、路由、分组、名称、图标、权限、开放状态、职责和规划阶段。导航权限复用既有 can 策略；未授权入口不展示，直接访问对应路由仍显示无权限。未开发模块均为 ComingSoonPage，明确“即将开放”，不提供编辑表单或写操作。

共享组件：AppShell、SidebarNavigation、Topbar、PageHeader、StatCard、StatusBadge、LoadingState、EmptyState、ErrorState。通用组件只接收显示 Props；UI 不导入 Mock 原始数据。修改前检查全部引用。

工作台基于授权数据展示统计、独立状态维度、角色范围待办、资源及供应商速览、报价摘要和最近活动。避免渐变、大图和动画装饰。状态色只辅助理解，同时保留中文文字。资源概览不是漏斗、实时健康或计费看板。活动每类仅显示最近一条真实授权记录，最多五类，不读取受限原始审计快照。

反馈：请求时展示 LoadingState；无授权数据展示明确空态；任一必要查询失败，整页显示通用错误及重试，不显示部分统计或内部异常详情。刷新为只读重新查询，不修改业务状态。

演示身份切换重建 Adapter；按身份/域给内容树设置 key，卸载旧数据，并通过请求清理标记拒绝过期结果。仅用户 ID 和业务域选项保存到 sessionStorage，刷新保留选择和路由；不保存业务记录、价格、客户身份或查询缓存。存储不可用时仍可演示。

原欢迎页保留在 /welcome，根路径进入 /dashboard。角色视角与系统说明路由当前仅为说明占位，实际身份切换位于顶部，不代表正式账号管理。所有未来阶段需单独授权，不自动开发。

## Stage 03：供应商模块

正式开放 /suppliers 与 /suppliers/:supplierId，复用 AppShell、PageHeader、统计卡和状态/反馈组件。表格提供名称/缩写检索、合作/启用/类别/负责人筛选、重置、排序和分页；筛选变更回到第一页。顶部统计基于主档授权范围，不随搜索条件变化，避免与筛选结果总数混淆。

新增和编辑使用 620px 抽屉，窄屏自适应单列；必填字段明确标识，错误提示中文。内置“仅填写虚构资料”提示，不提供密码/API Key 输入。保存中禁用重复操作；失败保持表单；并发冲突显示“重新加载最新资料”，不静默覆盖。

详情包含基础资料、合作联系人、按当前授权计算的资源摘要、可见主档历史与后续扩展占位。内部 ID 只读；长文本换行或在单元格内滚动，表格在容器内横向滚动。运营可启停/分配，采购仅维护授权资料，其他角色只读相应摘要或拒绝访问。按钮之外服务层仍鉴权。

停用与重置均二次确认；状态提示明确不修改关联资源。ErrorState 新增可选说明 Props，工作台原默认提示保持不变。AppShell 只调整会话写能力失效及 Mock 文案，未重写布局。原占位路由测试改用仍未开放的模型资源池，保留其导航/刷新/占位验收意图。

## Stage 04A：模型资源池与渠道详情

启用 /models、/models/:modelId、/channels/:channelId，统一深蓝侧栏、浅色内容区、PageHeader、StatCard、StatusBadge 和加载/空态/错误反馈。新页面用路由级懒加载；没有新图表或状态管理依赖。/channels 仍为后续管理占位，渠道详情从模型渠道表进入，不重复建立复杂列表。

资源池采用紧凑表格，分组展示模型名称/代码、厂商/业务域、版本/地区、类别/启停、供应商及渠道数量，以及质量、连通性、接入、开放的独立计数。每个计数标签带维度，不显示无依据的“模型测试通过”。顶部统计明确为当前授权目录口径，表格结果数单独反映筛选。

名称/代码、授权厂商、类别、地区、启用、可见渠道、供应商覆盖筛选可重置，筛选改变时回第一页，支持名称/渠道数排序。前台不展示供应商覆盖筛选、供应商家数卡片/列及身份表。供应商关联入口说明是筛选关联模型，不改变模型详情的全授权覆盖口径。

模型详情分基础信息、覆盖数量、类型分布、供应商覆盖、渠道清单与后续能力。供应商名称/缩写/状态取当前主档；主档停用与渠道启停分别标识。获准的供应商名称可跳转原供应商详情；原供应商资源摘要增加只读“查看关联模型”链接，不改表单和保存行为。

渠道清单展示 TPM/RPM/并发/TTFT 与各独立状态，未知值统一“未知”。渠道只读详情分基本关联、能力、独立状态与获准的技术引用，不渲染任何新增/编辑/OP 绑定按钮。技术属性未授权时行本身不出现，OP ID 真正为空时显示“未绑定”。

桌面 1440/1280px 和 390px 下表格仅在卡片内横向滚动；窄屏卡片与筛选堆叠，长名称换行。无资源模型保留目录信息，并显示空渠道状态；未授权/未知 ID 通用拒绝；失败不显示不完整统计，可重试。身份或业务域切换沿用 AppShell 数据子树隔离，新请求 hook 另行拦截旧响应。

## Stage 04B：渠道目录和主档维护

/channels 启用正式目录，复用 PageHeader/StatCard/StatusBadge/反馈组件和资源查询 hook；路由懒加载。统计来自当前授权 API：渠道、启用、待质量、待连通性、接入、开放独立计数；只有技术字段获准者看未绑定 OP 指标和筛选。搜索、厂商/模型/获准供应商、类型及五维状态、OP 绑定筛选只作用于表格，支持排序、分页、重置和空态。

详情保留模型/供应商导航和能力/独立状态；产品运营额外看到维护、历史和模拟绑定，其他角色继续只读。前台名称为稳定匿名渠道代号。列表技术更新时间不向无技术权限角色展示；不显示商业价格。

新增/编辑使用抽屉，保存失败保留输入并显示具体错误。能力留空明确表示未知，不强制为零；TTFT 标注毫秒。OP 为独立弹窗，显示“模拟绑定，未连接生产 OP”，预览前后值后再确认；绑定后禁用入口且不提供解绑。资源启停与演示数据重置单独确认并说明影响。

宽表水平滚动在表格容器内，不撑开页面；能力字段在窄屏单列，抽屉随视口收缩。验收尺寸 1440/1280/390px。不增加大型依赖或复杂审计平台。

## Stage 05A：采购寻源

/sourcing 为正式目录，提供授权统计、编号/当前可见标题、模型/状态/优先级/创建日期筛选、排序分页和空态；不提供采购客户筛选或未定义的负责人筛选。详情按模型分卡，每条独立展示目标要求、候选、辅助判断和覆盖；候选数、不同供应商数、人工初步符合数、距三家差额分别标明，不用大面积红色将“未开展”误导为调查失败。

新建/维护使用宽抽屉，运营受限信息与采购共享区域分开，禁止自动复制原文。至少一条模型明细，支持新增多个模型。能力空值提示未知，TTFT 明确毫秒；采购目标以整数基点录入并说明 8000=八折。已有明细模型只读，不提供隐式关联迁移或删除。保存失败保留输入；重复点击由表单 busy 与服务幂等标识共同处理。

候选抽屉从统一授权渠道读取，支持供应商、类型、TPM/RPM/并发下限、TTFT 上限、启用/质量/连通/接入/开放筛选。未知值不会通过数值下限筛选。当前已有关系按钮禁用，需在详情修改或重新评估。人工匹配和主单进度用独立确认对话框，说明与理由均为共享内容。跟进可展开查看中文字段标签的前后值，不展示研发字段代码作为业务文案。

复用现有 Shell/PageHeader/StatCard/StatusBadge/反馈与资源查询 hook；采购路由懒加载，无额外大型依赖。桌面表格在容器内横滚，1280/1440px 保持高密度；390px 表单单列、模型卡标题换行、表格不撑开页面，候选与进度操作可使用。

## Stage 05B：报价台账与商业视图

/quotes 正式开放为“采购报价管理”，分台账/询价跟进/有条件价格对照三个页签，/quotes/:quoteId 显示来源、证据、基准/规格、有效期、独立核验和确认、同渠道版本及本记录审计。列表以模型/供应商/渠道、折扣/价格口径、来源/状态/有效性为主，细节放详情，不强塞全部商业字段。

台账支持授权厂商/模型/供应商/渠道、状态、来源、币种、创建日期/有效期及需求过滤、排序分页。记录状态和时间标签同时展示，文字明确参考/待确认/正式/临时/到期。统计说明7天到期窗口和授权范围，不能把过期记录当当前成本。

录入抽屉将渠道关系、来源、价格规格、时间/证据分区；不自动填写官方刊例和 Token 单位。折扣为整数基点；金额用文本保留最多6位小数，未知不是0。各计量维度独立配置数量和单位。日期录入按北京时间00:00，截止时间不含；显示为北京时间。

正式确认和来源核验独立入口，采购不显示正式确认按钮，服务层仍拒绝越权；确认对话框要求明确勾选“仅模拟、不代表真实签署”。更正标题和原因突出“追加、不覆盖”。详情保留前序跳转和原有版本，不标唯一当前结算价。

渠道详情只向 quote:read 展示授权历史，寻源明细并列显示目标/关联报价及询价回复；前台、测试、运维不挂载商业查询。候选询价和完整历史链接沿用现有路由。复用 Shell、PageHeader、StatCard、状态/反馈、查询 hook，报价路由懒加载，无新依赖。1440/1280桌面表格容器内横滚，390px 表单单列、长记录 ID 换行，主页面不被撑宽。

## Stage 06A：采购分析工作台

/analytics/procurement正式开放“采购价格分析”，旧/analysis/purchase只读重定向兼容。深蓝侧栏/浅灰工作区沿用，共享PageHeader/StatCard/反馈/查询Hook，路由懒加载，零新增依赖。第一层覆盖指标与独立报价状态；第二层同模型渠道比较及历史趋势；第三层优惠、目标数字差、询价跟进、数据质量与分页报价明细。各表在卡片内横滚，报价详情下钻复用原路由。

筛选全部为授权选项，可重置。说明统计随普通筛选变化，报价筛选不冒充询价筛选。未知不补0，不同口径列具体原因。正式历史覆盖与当前正式生效分开，最近不标唯一成本；目标数字差始终伴随不可确认商业可比性提示。

趋势用轻量SVG，X轴为实际时间比例而非序号；Y轴为整数基点。分组图例展示币种/基准/规格与原录入状态。临时优惠空心圆/虚线、正式记录方形、纠错菱形且不连入真实调价线，文字和形状不只靠颜色；原始数值/时间可在明细查看。无完整口径或足够点时给原因，不画误导线。供应商时间缺失不回退到创建时间。1440/1280桌面布局、390单列筛选/双列小指标、长文本换行。

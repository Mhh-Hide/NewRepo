# UI 基础

使用 React + TypeScript 与 Ant Design，中文为默认展示语言。路由由 React Router 管理。
第 00 阶段交付为欢迎页；第 02 阶段扩展范围见下，后续未授权业务模块仍不得提前开发。

保持语义化标题、可读布局、移动端不溢出。业务 UI 放入对应 feature；共享组件只在有实际复用需求时提取，修改前检索所有引用。
后续加载、空态、错误反馈、表单校验、表格筛选规范随 PRD 确认。权限判断独立于 UI，隐藏字段不构成安全控制。

## Stage 02：应用外壳与工作台

采用浅灰背景、白色内容卡片、深蓝侧栏、克制的品牌蓝。默认简体中文，组件优先使用 Ant Design；图标显式依赖其官方 @ant-design/icons，不引入其他 UI 框架。标题约 27px，区块标题约 14px，正文 12–14px；数字用清晰的千位分隔，未知能力展示“未知”，不补零。

布局：桌面固定 232px 左侧栏，可收起为 76px；顶部展示系统名、Mock 标识、业务域和演示身份。中央 PageHeader 统一面包屑、标题、说明与只读刷新操作。1440px/1280px 优先，窄屏用抽屉导航；卡片随宽度重排，宽表格在卡片内横向滚动，不让整个页面溢出。

导航唯一真值为 src/app/navigation.tsx，含 ID、路由、分组、名称、图标、权限、开放状态、职责和规划阶段。导航权限复用既有 can 策略；未授权入口不展示，直接访问对应路由仍显示无权限。未开发模块均为 ComingSoonPage，明确“即将开放”，不提供编辑表单或写操作。

共享组件：AppShell、SidebarNavigation、Topbar、PageHeader、StatCard、StatusBadge、LoadingState、EmptyState、ErrorState。通用组件只接收显示 Props；UI 不导入 Mock 原始数据。修改前检查全部引用。

工作台基于授权数据展示统计、独立状态维度、角色范围待办、资源及供应商速览、报价摘要和最近活动。避免渐变、大图和动画装饰。状态色只辅助理解，同时保留中文文字。资源概览不是漏斗、实时健康或计费看板。活动每类仅显示最近一条真实授权记录，最多五类，不读取受限原始审计快照。

反馈：请求时展示 LoadingState；无授权数据展示明确空态；任一必要查询失败，整页显示通用错误及重试，不显示部分统计或内部异常详情。刷新为只读重新查询，不修改业务状态。

演示身份切换重建 Adapter；按身份/域给内容树设置 key，卸载旧数据，并通过请求清理标记拒绝过期结果。仅用户 ID 和业务域选项保存到 sessionStorage，刷新保留选择和路由；不保存业务记录、价格、客户身份或查询缓存。存储不可用时仍可演示。

原欢迎页保留在 /welcome，根路径进入 /dashboard。角色视角与系统说明路由当前仅为说明占位，实际身份切换位于顶部，不代表正式账号管理。所有未来阶段需单独授权，不自动开发。

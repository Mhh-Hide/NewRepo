# 产品范围

中文名称：MaaS 模型资源全生命周期管理平台。
英文名称：MaaS Resource Lifecycle Management。

平台从上游模型供应商获取 Token/API 资源，为下游企业客户提供模型调用服务。主要服务产品运营、采购、模型测试、供应商、运维。

MVP 模块职责：

| 模块       | 职责与边界                               |
| ---------- | ---------------------------------------- |
| 供应商管理 | 维护供应商档案与授权数据边界             |
| 模型管理   | 维护厂商提供的模型及关联关系             |
| 渠道管理   | 管理供应商、模型与渠道类型构成的操作资源 |
| 采购寻源   | 支持资源采购寻源；审批与流程待 PRD       |
| 报价历史   | 区分报价类别，保留已确认价格变化         |
| 模型测试   | 独立表达质量测试与连通性测试             |
| 供应商整改 | 记录整改事项；触发条件与闭环待 PRD       |
| 运营分析   | 基于授权数据分析；指标口径待确认         |

本次仅第 00 阶段工程基础与欢迎页。以上均未实现。

不在本期：销售折扣申请、客户价格自动配置、OP 生产接口写入、MaaS Monitor 实时监控、计量、账单、收入。
不连接生产系统，所有数据模拟。模块字段、状态机、审批路径、分析口径须等待详细 PRD。

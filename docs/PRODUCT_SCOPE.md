# 产品范围

中文名称：MaaS 模型资源全生命周期管理平台。
英文名称：MaaS Resource Lifecycle Management。

平台从上游模型供应商获取 Token/API 资源，为下游企业客户提供模型调用服务。主要服务产品运营、采购、模型测试、供应商、运维。

MVP 模块职责：

| 模块       | 职责与边界                               |
| ---------- | ---------------------------------------- |
| 供应商管理 | 维护供应商档案与授权数据边界             |
| 模型管理   | 维护厂商提供的模型及关联关系             |
| 渠道管理   | 管理供应商、模型与渠道类型构成的操作资源 |
| 采购寻源   | 支持资源采购寻源；审批与流程待 PRD       |
| 报价历史   | 区分报价类别，保留已确认价格变化         |
| 模型测试   | 独立表达质量测试与连通性测试             |
| 供应商整改 | 记录整改事项；触发条件与闭环待 PRD       |
| 运营分析   | 基于授权数据分析；指标口径待确认         |

第 00 阶段已完成工程基础与欢迎页；第 01 阶段仅实现核心类型、权限与只读 Mock 查询，以上业务模块页面均未实现。

不在本期：销售折扣申请、客户价格自动配置、OP 生产接口写入、MaaS Monitor 实时监控、计量、账单、收入。
不连接生产系统，所有数据模拟。模块字段、状态机、审批路径、分析口径须等待详细 PRD。

## Stage 02 已授权范围

本阶段已建立统一 Application Shell、导航、身份/业务域切换、只读工作台和其余模块占位页。未实现完整供应商、模型、渠道、采购、报价、测试、整改、治理或分析业务页，也没有业务写 API。原欢迎页兼容保留。

路由：/dashboard；/models、/suppliers、/channels；/sourcing、/quotes、/tests、/remediations、/governance；/analysis/purchase、/analysis/tests；/system/roles、/system/about。除工作台外均为统一占位；未授权直接访问返回无权限提示，未知路径返回未找到。/welcome 保留原页面，/ 重定向到工作台。

规划标识仅供验收：供应商 Stage 03；模型/渠道 Stage 04；寻源 Stage 05；报价 Stage 05—06；测试/整改 Stage 07；治理 Stage 08；分析阶段待确认。这不是后续开发授权。

## Stage 03 开放范围

供应商管理 /suppliers 及 /suppliers/:supplierId 已开放主档列表、新增、编辑、负责人分配、启停、详情和变更历史，支持本地 Mock 持久化。其余业务模块继续占位；不新增报价、渠道编辑、测试结果、供应商门户或真实生产接口。Stage 04 未开始。

## Stage 04A 开放范围

已开放 /models 模型资源池、/models/:modelId 模型详情和 /channels/:channelId 渠道只读详情，并与供应商详情互相导航。提供授权数据的搜索、筛选、覆盖与能力/状态查询。/channels 管理列表仍为后续阶段占位。没有模型/渠道编辑、OP ID 写入、Key 管理、采购调价、测试执行、上线或真实系统接入；Stage 04B 未开始。

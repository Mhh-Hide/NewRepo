# Stage 07F 交付记录

基线：`d64039273de4b78015f3b500dfe0c0282a44a2dc`。分支：`stage-07f-procurement-redesign`。

保留采购报价及价格历史、供应商多行报价、客户需求三级展开、渠道自动命名、人员及厂商范围视角。整批写入失败不产生半批渠道或价格；销售进度使用独立字段投影。

原始 Excel 可在本机访问；沿用 Stage 07E 的受控加载机制，原始文件及私有标准化数据不提交。公开种子中的报价、合同、用量和员工均为独立演示样本；公开模型目录不代表实际接入渠道。

## 已知限制

- 原型仍使用浏览器演示身份及本地适配器，不是生产认证或服务端权限系统。
- 未确认获取的旧渠道仍可能显示“待分配”，需通过既有交付操作补齐岗位交接。
- 数字输入控件可能补两位小数，原生日期输入的显示顺序取决于浏览器区域；列表按 YYYY-MM-DD 展示。
- 部分旧模块仍保留模拟渠道名称及较多筛选项，本次收尾不再扩展改版范围。
- 模型目录不是实时同步目录；真实商务价格与合同结果没有可靠来源时不作为实际记录导入。
